# Projetos Avançados de Sistemas (PAS)

Repositório destinado aos exercícios e práticas da disciplina **Projetos Avançados de Sistemas** (6º Semestre) do curso de Sistemas de Informação/Engenharia da **UNEB** (Universidade do Estado da Bahia).

## 🚀 Sobre o Repositório

Este repositório tem como objetivo armazenar as resoluções dos exercícios e trabalhos propostos ao longo do semestre. Os exercícios abordam conceitos de engenharia de software, padrões de projeto e desenvolvimento de sistemas.

## 📁 Estrutura de Exercícios

Atualmente, o repositório contém as seguintes práticas:

- **[`exercicio_Ponto/`](./exercicio_Ponto/)**: Exercício focado em conceitos fundamentais (manipulação de coordenadas de um ponto).
- **[`exercicio_agendaTelefonica/`](./exercicio_agendaTelefonica/)**: Implementação de um sistema de Agenda Telefônica.
- **[`exercicio_login/`](./exercicio_login/)**: Prática envolvendo sistema de Autenticação e Login.
- **[`exercicio_memoria/`](./exercicio_memoria/)**: Exercício relacionado à manipulação/jogo de Memória.

## 💻 Linguagens e Tecnologias

A maior parte dos exercícios possui implementações comparativas ou focadas em diferentes paradigmas/linguagens. As linguagens predominantes até o momento são:

- ![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white) **Java**
- ![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54) **Python**

## 📖 Como Executar

1. Clone este repositório para a sua máquina local:
   ```bash
   git clone https://github.com/seu-usuario/pas.git
   ```
2. Navegue até o diretório do exercício que deseja testar:
   ```bash
   cd pas/nome_do_exercicio
   ```
3. Acesse a pasta da linguagem desejada (`java/` ou `python/`) e execute os scripts seguindo o padrão de cada tecnologia.
